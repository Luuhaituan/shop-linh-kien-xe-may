I. TỔNG QUAN DỰ ÁN
==============================================================
Đây là một website thương mại điện tử bán linh kiện xe máy, được xây dựng
bằng nền tảng ASP.NET WebForms kết hợp với Entity Framework (Database-First)
để giao tiếp với cơ sở dữ liệu SQL Server.

Dự án được tổ chức theo mô hình phân tầng:
  - Tầng giao diện  : Các trang .aspx (ASPX WebForms)
  - Tầng API        : Các HTTP Handler (.ashx) trả về JSON
  - Tầng dữ liệu   : Entity Framework Model (.edmx) ánh xạ từ SQL Server

IV. CÁC API ENDPOINT ĐÃ HOÀN THÀNH (ASHX - trả về JSON)
==============================================================

  1. GioHangApi.ashx       - API QUẢN LÝ GIỎ HÀNG (139 dòng)
     Các action hỗ trợ:
       + action=get    : Lấy danh sách sản phẩm trong giỏ hàng
       + action=add    : Thêm sản phẩm vào giỏ (có thể thêm số lượng cụ thể)
       + action=remove : Xóa sản phẩm khỏi giỏ hàng
       + action=update : Cập nhật số lượng sản phẩm (xóa nếu qty=0)
     Yêu cầu : Đăng nhập (kiểm tra Session["User"])
     Tự động : Tạo giỏ hàng mới nếu người dùng chưa có

  2. DatHangApi.ashx        - API ĐẶT HÀNG / THANH TOÁN (100 dòng)
     Nhận dữ liệu : ten, sdt, diaChi, ptThanhToan
     Xử lý        :
       + Tính tổng tiền từ giỏ hàng hiện tại
       + Cập nhật thông tin cá nhân người dùng (HoTen, SoDienThoai, DiaChi)
       + Tạo đơn hàng mới với trạng thái "Chờ xác nhận"
       + Sao chép chi tiết giỏ hàng sang chi tiết đơn hàng
       + Xóa sạch giỏ hàng sau khi đặt thành công
     Trả về : { success, maDonHang }

  3. DonHangApi.ashx        - API XEM DANH SÁCH ĐƠN HÀNG (58 dòng)
     Lấy toàn bộ đơn hàng của người dùng hiện tại
     Sắp xếp : Đơn mới nhất lên đầu (OrderByDescending)
     Trả về   : Danh sách đơn hàng kèm chi tiết từng sản phẩm

  4. HuyDonHangApi.ashx     - API HỦY / TRẢ HÀNG (97 dòng)
     Luồng 1 - Hủy đơn (action=huy):
       + Chỉ cho hủy khi trạng thái là "Chờ xác nhận"
       + Cập nhật trạng thái → "Đã hủy"
     Luồng 2 - Trả hàng (action=hoanhang):
       + Chỉ cho trả khi đơn đã "Hoàn thành"
       + Kiểm tra chính sách 7 ngày kể từ ngày đặt
       + Cập nhật trạng thái → "Trả hàng/Hoàn tiền"

  5. MuaLaiApi.ashx         - API MUA LẠI ĐƠN HÀNG CŨ (76 dòng)
     Lấy toàn bộ sản phẩm từ đơn hàng cũ và ném vào giỏ hàng hiện tại
     Tự động cộng dồn số lượng nếu sản phẩm đã có trong giỏ

  6. ChiTietSPApi.ashx      - API CHI TIẾT SẢN PHẨM (58 dòng)
     Nhận: ?id={maLinhKien}
     Trả về: TenLinhKien, GiaBan, HinhAnh, MoTa, SoLuongTon

  7. LinhKienApi.ashx       - API DANH SÁCH LINH KIỆN (2.077 bytes)

  8. DanhMucApi.ashx        - API DANH MỤC SẢN PHẨM (1.247 bytes)

  9. CapNhatThongTinApi.ashx - API CẬP NHẬT THÔNG TIN CÁ NHÂN (58 dòng)
     Nhận dữ liệu : sdt, diaChi
     Xử lý        : Cập nhật SoDienThoai, DiaChi vào database + Session
