I. TỔNG QUAN HỆ THỐNG
================================================================
Website thương mại điện tử VanDonMotor là hệ thống bán linh
kiện xe máy trực tuyến, cho phép khách hàng:
    - Duyệt sản phẩm theo danh mục / dòng xe
    - Thêm vào giỏ hàng và đặt hàng
    - Thanh toán trực tuyến (Chuyển khoản ngân hàng qua SePay,
      hoặc COD – Thanh toán khi nhận hàng)
    - Đánh giá sản phẩm sau khi mua
    - Chat trực tiếp với nhân viên hỗ trợ

  Và cho phép quản trị viên:
    - Quản lý sản phẩm / danh mục / dòng xe
    - Quản lý khách hàng / nhân viên
    - Xử lý đơn hàng và quản lý tồn kho
    - Tạo mã khuyến mãi
    - Xem thống kê doanh thu và nhật ký hoạt động

Hệ thống tuân theo mô hình 3 tầng:
  - Tầng trình bày   : Các trang ASPX + JS (app.js, auth.js)
  - Tầng API          : Các HTTP Handler (.ashx) trả JSON
  - Tầng dữ liệu     : Entity Framework (EDMX) + SQL Server

VII. CÁC TÍNH NĂNG ĐÃ HOÀN THÀNH
================================================================
[✓] 1. ĐĂNG KÝ TÀI KHOẢN
       - Họ tên, Tên đăng nhập, Email, SĐT, Mật khẩu
       - Kiểm tra trùng TenDangNhap, Email, SDT
       - Tích hợp Google reCAPTCHA v2
[✓] 2. ĐĂNG NHẬP / ĐĂNG XUẤT
       - Cho phép đăng nhập bằng username hoặc email
       - reCAPTCHA v2
       - Phân quyền Admin → Admin.aspx, User → index.aspx
[✓] 3. QUÊN MẬT KHẨU
       - Xác minh cặp TenDangNhap + Email
       - Đặt lại mật khẩu (hash)
[✓] 4. GIỎ HÀNG
       - Thêm/Sửa/Xóa, cập nhật số lượng
       - Lưu DB (không mất khi reload)
[✓] 5. ĐẶT HÀNG & THANH TOÁN
       - Nhập Tên người nhận, SĐT, Địa chỉ
       - Phương thức: COD hoặc Chuyển khoản
       - Áp dụng mã giảm giá (validate server-side)
       - Tự động trừ tồn kho
       - Tạo mã vận đơn VDyyMMddHHmmss
[✓] 6. THANH TOÁN SEPAY
       - Tạo QR code chuyển khoản với nội dung là MaVanDon
       - SePay gọi webhook khi có CK vào
       - Đối chiếu mã vận đơn + số tiền → tự cập nhật
         TrangThaiThanhToan = "Đã thanh toán"
         TrangThaiDon = "Đã xác nhận"
[✓] 7. QUẢN LÝ ĐƠN HÀNG (User)
       - Lịch sử đơn, hủy khi "Chờ xác nhận"
       - Trả hàng trong 7 ngày sau "Hoàn thành"
       - Mua lại (đổ SP cũ vào giỏ)
[✓] 8. CẬP NHẬT THÔNG TIN CÁ NHÂN
       - Tên, Email (TaiKhoan.aspx)
       - SĐT, Địa chỉ (TaiKhoan.aspx)
       - Đổi mật khẩu (ChangePasswordApi)
[✓] 9. ĐÁNH GIÁ SẢN PHẨM
       - Chỉ người đã mua mới được đánh giá
       - Số sao (1-5) + nội dung
       - Tự tính điểm trung bình
       - Admin có thể ẩn / xóa đánh giá
[✓] 10. CHAT HỖ TRỢ
       - Khách tạo phiên chat với nhân viên
       - Đánh dấu đã đọc (DaDocKhach / DaDocNhanVien)
       - Admin có thể xem tất cả phiên
       - Admin có thể xóa phiên
[✓] 11. KHU VỰC QUẢN TRỊ (12 chức năng)
       1) Quản lý Sản phẩm  (CRUD + Upload ảnh + dòng xe)
       2) Quản lý Danh mục   (CRUD, không xóa nếu còn SP)
       3) Quản lý Dòng xe    (CRUD + gán SP tương thích)
       4) Quản lý Khách hàng (DS, khóa/mở, xem LS mua)
       5) Quản lý Người dùng (CRUD NV, reset MK, đổi vai trò)
       6) Quản lý Đơn hàng   (DS, cập nhật TT, hủy, vận đơn)
       7) Quản lý Khuyến mãi (CRUD mã GG, hạn dùng)
       8) Quản lý Kho         (Tồn kho, phiếu nhập/xuất/điều chỉnh)
       9) Quản lý Đánh giá   (Ẩn / hiện / xóa)
       10) Thống kê           (Doanh thu theo ngày, top SP/KH)
       11) Nhật ký            (Log hoạt động, IP)
       12) Chat               (Xem & trả lời khách hàng)

X. HƯỚNG DẪN SỬ DỤNG PLANTUML
================================================================
Bước 1: Mở trang https://www.plantuml.com/plantuml/uml/

Bước 2: Copy toàn bộ nội dung file .puml trong folder
Bao_cao hoặc Bao_cao/UML_CAC_BIEU_DO_CON/

Bước 3: Dán vào ô text bên trái của plantuml.com

Bước 4: Hình sẽ tự động render bên phải

Bước 5: Có thể nhấn "Export as PNG/SVG" để tải về

Hoặc dùng VS Code với extension "PlantUML" để preview trực
tiếp trong IDE.

Lưu ý: Tất cả đường nối trong biểu đồ đều dùng đường thẳng
(dùng "->" hoặc "-->" thay vì "-[#弧]->"). Bố cục được
thiết kế đơn giản, dễ đọc.
